Changes since v0.3.3:

- Read-only files in the terminal now support F2 switching between wrapped and
  unwrapped views. Logical-line navigation, horizontal caret reveal, resizing
  and selection preserve source bytes. Pending preparation can be cancelled.
- Read-only wrapping prefers spaces and tabs, including when reconstructing
  earlier rows. Long words still wrap at character boundaries.
- Unwrapped terminal views reuse verified viewport mappings for nearby
  navigation. Long off-screen ASCII prefixes avoid repeated glyph allocation.
- CSV formula calculation avoids unnecessary cache allocations for short
  numeric operands. Exact arithmetic, stored formula text, displayed results,
  and both Convert to Value commands retain their existing behavior.
- Internal immutable source snapshots preserve exact bytes and separate
  selection ranges for future print/preview integration. This does not add a
  Print command or native preview yet.

Validation includes source-preservation, cancellation, formula/dependency and
scripted terminal input tests. Component measurements and their limitations are
recorded under performance/2026-10-02-terminal-reveal and
performance/2026-10-02-csv-view. They do not establish native input-to-screen
latency or complete the final desktop responsiveness audit.

This release retains v0.3.3's filename/dirty state in the native window title,
Markdown mode checkmark, consistent pointer-opened menus and inset status bar.
The GUI's large-file/session migration, visible control-byte mapping, multiple
selection, and native printing/layout preview remain in development.
