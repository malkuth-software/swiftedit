Changes since v0.3.5:

- Rendered Markdown parsing and inert display-text preparation run on an owned
  background worker. Escape or switching back to source cancels pending work.
  Source replacement revokes obsolete results; reopening a cancelled view starts
  fresh preparation. Source bytes and saved Markdown remain unchanged.
- Markdown painting and link hit testing use a vertical extent index, preventing
  tall quotes or table borders from forcing all their off-screen words through
  the drawing path. Intersecting decorations remain visible.
- A bounded cache reuses word measurements within one layout and font style.
  Layout runs share their prepared link destinations, avoiding a full URL copy
  for every word. Space-only runs retain geometry and decorations without
  submitting empty text drawing to the native renderer.
- Preparation scheduling stops after completion or cancellation. Native checks
  cover completed presentation, settled idle, and closing with work pending;
  timing now separates synchronous layout from native presentation and observer
  stalls. Raw measurements and limitations are recorded in
  performance/2026-10-02-markdown-visibility.

Native text shaping and layout still run on the UI thread. Worker cancellation
and close do not have guaranteed time bounds, and these changes do not establish
that the complete responsiveness audit has passed.

CSV stored formulas and both Convert to Value commands retain their existing
behavior. Large-file GUI integration, editable visible control-byte mapping,
multiple selection, native printing and Markdown print preview remain unfinished.
This release continues to use the frozen aaca5d0 GUI.Forms and picker SDK.
