Changes since v0.3.1:

- Find wildcard flags now follow the exact edited characters. Inserting or
  deleting repeated characters no longer transfers a flag to a neighboring
  occurrence. GUI query undo/redo restores text, flags and selection together.
- Query-field painting avoids repeated measurement of identical display labels.
- Read-only terminal scrolling prepares source context according to the visible
  viewport, reducing repeated work while preserving Unicode boundary checks.
- Markdown layout counts table borders and quote decorations against its storage
  limits and reports oversized layouts without changing source content.
- Filename and diagnostic labels preserve literal ampersands.

This release also includes tested Session-to-document-page production work for
the future GUI migration. It does not yet replace the GUI's existing editor.
Dynamic native window titles, removal of the extra filename row, consistent
pointer-opened menu focus, full large-file GUI editing/viewing, multiple selection,
and native printing/layout preview remain unfinished. The repository contains
raw responsiveness measurements and their limitations; these are component and
CI observations, not a completed physical desktop responsiveness audit.
