Changes since v0.3.2:

- The native window title shows the filename (or Untitled), with an asterisk
  for unsaved changes. The redundant filename row below the menu is removed.
- Mouse-opened menus no longer preselect the first item. Keyboard opening keeps
  an actionable initial selection. Markdown Rendered View shows its active
  state with a checkmark, independently of pointer or keyboard highlighting.
- The status bar has an inset border and improved text spacing.
- Native CSV tests now exercise stored formula entry, the displayed result,
  both Convert to Value commands, undo, and saved formula source.
- Mac Find-window tests wait for actual visibility before sending their owned
  synthetic key events, avoiding a timing assumption about window presentation.

The new public GUI.Forms/picker SDK is pinned by revision and archive digest for
each platform. Dynamic-title transitions, including Unicode filenames and
unsaved/clean/Untitled states, are checked by native tests. Mac captures were
visually inspected for menu state, document placement and status-bar borders.

Large-file GUI migration, multiple selection, native printing/layout preview,
and the final physical desktop responsiveness audit remain unfinished. Terminal
logical-line paging groundwork is included; read-only wrap switching is not yet
connected to that groundwork.
