Changes since v0.3.9:

- Adopts standalone GUI.Forms at `e589142ffc6f5c2aaed46754460031919c44aa2c`
  and the File Manager document picker at
  `964261f33031db3cec48fd4cacd84f78f3843548`, built from pinned sources with
  the shared LLVM 22 toolchain and consumed through their public CMake packages.
- Imports verified provider compiler caches and retains SwiftEdit compilation,
  renderer and runtime caches across builds. Adds standard application, check
  and package targets and matching presets for all three platforms.
- Preserves native regression tests, package startup checks and runtime
  dependency checks on Windows x64, Linux x64 and Apple silicon macOS.
- Includes LLVM runtime license notices with the application packages.

This release updates the shared toolkit and build infrastructure. It does not
complete the remaining large-file GUI editing, native printing or physical
input-latency work. Windows and Linux archives are portable; the macOS app is
ad-hoc signed and is not notarized.
